Privacy Policy

Effective date: 2026 · Stateless, database-free open-source GitHub App.

1. Zero Database & Zero Persistent Storage

Open Workers is built on a strictly database-free architecture. The application does not persist repository source code, license configurations, user accounts, cookies, or personal profiles.

2. Data Processed On-Demand

  • Public Repository Analyzer: Queries public GitHub REST API endpoints (/repos/{owner}/{repo}, /license, and root /contents) strictly on demand when you submit a repository identifier.
  • GitHub App Installations: When explicitly triggered to open a license pull request, the server mints a short-lived installation access token via @octokit/app solely to inspect whether a LICENSE file exists, create a branch, commit the generated LICENSE, and open a pull request.
  • Webhook Verification: Incoming webhook payloads are validated in memory using X-Hub-Signature-256 HMAC SHA-256 verification and delivery deduplication caches in memory only.

PR authorization: A user-provided GitHub token is processed in memory to verify identity. The App checks that user’s write permission on the selected repository. Tokens are not persisted or logged by the application. Use HTTPS outside local development.

Community generators: Form inputs are processed on demand and returned as Markdown. They are not saved or sent to GitHub.

3. Third-Party Sharing & Analytics

We do not sell, rent, or share any repository metadata or user information with third parties, and the web interface includes zero third-party advertising or behavioral tracking scripts.

4. Contact & Data Inquiries

For privacy questions or security reports, open an issue on github.com/ayushcmd/license-advisor or email ayush_24a12res897@iitp.ac.in.
