Support & Troubleshooting

Answers to common questions about repository analysis, rate limits, and GitHub App pull requests.

Common Questions

Why did the Repository Analyzer hit a GitHub rate limit?

Unauthenticated browser requests to api.github.com are capped by GitHub at 60 requests per hour per IP address. Wait for the reset timestamp displayed below the analyzer or run the Node.js backend with GitHub App authentication.

Why does the analyzer show "Unrecognized License File"?

GitHub's Licensee detector matches standard SPDX templates. Adding custom header banners, combining two licenses into one file, or editing license clauses can produce NOASSERTION. Use the License Explorer to generate a verbatim SPDX-compliant LICENSE.

Why can't I trigger an automated pull request in static mode?

Opening pull requests securely requires a signed GitHub App JWT and installation token generated on the Node.js server. Never place private keys in client-side code.
