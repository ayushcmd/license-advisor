      4. First-Time Contributor Automation

      Generate friendly, informative welcome greetings for new contributors with links to community standards and idempotent comment markers (`<!-- open-workers:welcome -->`).

      Welcome Message Generator

      Preview Message

      Click "Generate Welcome Preview" to see formatted message.

      Opt-In Webhook Automation via `.github/open-workers.yml`

      To enable automatic welcomes, label assignment, and size labeling on pull request events, commit this configuration to your repository default branch:

      version: 1
enabled: true
issues:
  labeling:
    enabled: true
pullRequests:
  sizeLabeling:
    enabled: true
  welcome:
    enabled: true
